# Codex Chat Mobile 手工测试用例

> 在手机浏览器（或桌面浏览器 390×844 手机视口）打开 Web UI 执行。
> 每个用例标注：步骤 → 预期结果 → ☐ 勾选框。

## 前提条件

```bash
npm install && npm test && npm start
# 或在指定端口：
PORT=3001 WORK_DIR=/your/project CODEX_SANDBOX=workspace-write CODEX_APPROVAL_POLICY=on-request node server.js
```

---

## TC-1: 基础会话 — 发送消息 + 流式回复

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1.1 | 打开 `http://localhost:3001` | 页面加载，header 显示 "Codex Chat"，状态灯 ○ |
| 1.2 | 在输入框输入 `hello`，点 ↑ 发送 | 用户气泡出现，显示 "hello" |
| 1.3 | 等待回复 | Codex 的回复逐字符出现（流式），最终完成 |
| 1.4 | 检查状态栏 | status-detail 行显示 📁项目 · 🛡sandbox · ○ |

☐ TC-1 通过
