接口参考速查

本页是 codex-chat-mobile 对外接口的速查手册，包含 HTTP 路由和 Socket.IO 事件签名。

HTTP 接口

方法 · 路径 鉴权 请求 响应
GET /health 需 token — {status, sessionId, busy, sessionState, versions, timestamp}
GET /push/vapid-public-key 无 — {key}
POST /push/subscribe 无 PushSubscription {ok:true}

Socket.IO 客户端到服务端

核心交互

事件 参数 返回
user:message text、attachments[] 无 ack
user:interrupt — 无 ack
user:approval approvalId、decision 无 ack

会话 session:*

事件 参数 返回
session:new cwd {ok:true}
session:list — {sessions, codexSessions, currentSessionId}
session:select sessionId {ok:true, sessionId}
session:fork instanceId、threadId {ok:true, sessionId, instanceId}
session:switch instanceId 无 ack
session:history sessionId {messages, title}

线程 thread:*

事件 参数 返回
thread:list archived、limit、searchTerm {ok:true, threads, nextCursor}
thread:select threadId、title {ok:true, sessionId, instanceId}
thread:history threadId {ok:true, thread, messages}
thread:archive threadId {ok:true, threadId}
thread:rename threadId、name {ok:true, threadId, name}
thread:delete threadId {ok:true, threadId}

Admin admin:*

事件 参数 返回
admin:unlock confirmText {ok:true, adminMode:true}
admin:lock — {ok:true, adminMode:false}
admin:configWrite keyPath、value {ok:true, result}
admin:fsWriteFile path、dataBase64 {ok:true, result}

Socket.IO 服务端到客户端

agent:event 信封

信封格式
{seq, epoch, sessionId, instanceId, cwd, ts, type, payload}

事件类型

type 用途
init 连接建立
status 会话状态
status_line git + context 状态行
text_delta 文本增量
reasoning 推理增量
tool_use 工具调用开始
tool_result 工具调用结果
tool_output_delta 工具输出增量
approval_request 审批请求
user_input_request 用户输入请求
approval_revoked 审批撤销
result turn 终态
error 错误
system 系统消息
instances 实例列表
session_list 会话列表
thread_event 原生线程事件
raw_item 未识别 item 兜底
