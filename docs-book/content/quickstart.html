快速开始

本地起一套 codex-chat-mobile 的最短路径。

前置条件

  • Node.js：≥ 20
  • Codex CLI：已安装并登录（codex 在 PATH 上，或用 CODEX_BIN 指定）

安装步骤

1. 克隆仓库

命令
git clone https://github.com/Ike-li/codex-chat-mobile.git
cd codex-chat-mobile

2. 安装依赖

命令
npm install

3. 配置环境

命令
cp .env.example .env
编辑 .env，至少设 WORK_DIR 指向你的工作区

4. 运行测试

命令
npm test

5. 启动服务

命令
npm start

6. 打开浏览器

访问
本机浏览器打开 http://127.0.0.1:3001

环境变量

变量 默认值 说明
PORT 3001 HTTP 端口
HOST 127.0.0.1 绑定地址
AUTH_TOKEN 空 共享密钥
WORK_DIR — 主工作目录
WORK_DIRS 空 额外工作目录白名单
CODEX_BIN codex Codex CLI 路径
CODEX_APPROVAL_POLICY on-request 审批策略
CODEX_SANDBOX workspace-write 沙箱模式
IDLE_TIMEOUT_MS 600000 空闲超时（10 分钟）

最小配置

.env 最小配置
WORK_DIR=/path/to/your/project

从手机连接

局域网访问

  1. 设置 HOST：HOST=0.0.0.0
  2. 设置 AUTH_TOKEN：非空强 token
  3. 手机访问：http://<开发机IP>:3001
注意
纯 http:// 局域网 装不了 PWA、收不到推送。想要完整体验需 HTTPS。

HTTPS 访问

推荐 Tailscale Serve，详见 远程访问方案。

验证安装

检查服务状态

健康检查
curl http://127.0.0.1:3001/health

返回：

响应
{"status":"ok","sessionId":"...","busy":false,"sessionState":"idle","versions":{"codex":"..."},"timestamp":...}

发送测试消息

  1. 打开 http://127.0.0.1:3001
  2. 在输入框输入「列出当前目录」
  3. 观察流式响应

常见问题

找不到 codex 命令

解决方案
在 .env 中设置 CODEX_BIN=/path/to/codex

WORK_DIR 不存在

解决方案
确保 WORK_DIR 指向存在的目录

端口被占用

解决方案
在 .env 中设置 PORT=其他端口

手机无法连接

解决方案
  1. 确保 HOST=0.0.0.0
  2. 确保 AUTH_TOKEN 非空
  3. 确保手机和电脑在同一局域网
  4. 检查防火墙设置
