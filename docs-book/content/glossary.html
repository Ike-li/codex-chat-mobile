核心术语

术语 定义
Codex CLI OpenAI 开发的 AI 编程助手命令行工具
app-server Codex CLI 的长驻子进程模式，通过 JSON-RPC 2.0 over stdio 通信
thread 会话线程，跨 Codex App/Web 的会话主事实源
turn 一次对话轮次，从用户输入到 AI 响应完成
item turn 中的元素（文本、命令、工具调用等）
审批（approval） app-server 发来的 S→C 请求，需要用户批准或拒绝
信封（envelope） agent:event 的包装格式，包含 seq、type、payload 等字段
catch-up 断线恢复机制，从重放缓冲增量补发错过的事件
steer 在 turn 运行中发送新输入，引导 AI 方向
instance 一个活跃的 app-server 会话实例，对应一个标签
WORK_DIR 主工作目录，Codex CLI 在此目录下运行
WORK_DIRS 额外工作目录白名单，逗号分隔
AUTH_TOKEN 共享密钥，用于非 loopback 访问鉴权
VAPID Web Push 的 Voluntary Application Server Identification
PWA Progressive Web App，可安装的 Web 应用
raw_item 未识别 item type 的可见兜底信封
ApprovalBroker 审批分类与决议模块
CodexAppServerSession JSON-RPC 桥的核心类，管理 app-server 子进程
protocol:check 检查协议覆盖与漂移的脚本
.protocol/stable/ pin 住的协议基线，由 generate-ts 导出

协议术语

术语 定义
JSON-RPC 2.0 远程过程调用协议，app-server 使用的通信协议
stdio 标准输入输出，用于子进程通信
NDJSON Newline Delimited JSON，每行一个 JSON 对象
S→C 请求 Server to Client 请求，必须应答（如审批）
S→C 通知 Server to Client 通知，不需要应答
C→S 请求 Client to Server 请求（如 turn/start）
C→S 通知 Client to Server 通知（如 initialized）
experimental 实验性方法，需 feature flag 隔离
generate-ts Codex CLI 的协议导出工具

UI 术语

术语 定义
审批卡片 显示审批请求的 UI 组件，包含批准/拒绝按钮
命令卡片 显示命令执行结果的 UI 组件
reasoning 区块 显示 AI 推理过程的折叠区域
状态栏 显示 cwd、sandbox、approval policy 等状态的区域
历史抽屉 浏览过去会话的侧边栏
实例标签 顶部标签，隔离多个活跃对话
斜杠命令 以 / 开头的命令（如 /status、/diff）

安全术语

术语 定义
loopback 本机回环地址（127.0.0.1 或 ::1）
timing-safe 时间安全比较，防止时序攻击
owner-only 仅文件所有者可访问的权限设置
设备信任 新设备需已信任设备批准的机制
Admin 门控 ENABLE ADMIN 解锁 + 逐操作确认
CSP Content Security Policy，内容安全策略
symlink 防御 防止符号链接攻击的安全措施
