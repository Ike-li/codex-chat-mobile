Socket.IO 接口概述

浏览器通过 Socket.IO 与 server.js 通信，所有事件通过 agent:event 信封下发。

接口约定
统一 ack 格式：ackOk → {ok:true, ...} 或 ackError → {ok:false, error}
事件注册：on(socket, 'event', handler)
错误处理：handler 抛错自动回 error 信封

客户端到服务端事件

核心交互

事件 参数 返回
user:message text、attachments[] 无 ack，异步经 agent:event 回流
user:interrupt — 无 ack
user:approval approvalId、decision 无 ack

会话 session:*

事件 参数 返回
session:new cwd {ok:true}
session:list — {sessions, codexSessions, currentSessionId}
session:select sessionId {ok:true, sessionId}
session:fork instanceId、threadId {ok:true, sessionId, instanceId}
session:switch instanceId 无 ack
session:history sessionId {messages, title}

线程 thread:*

事件 参数 返回
thread:list archived、limit、searchTerm {ok:true, threads, nextCursor}
thread:select threadId、title {ok:true, sessionId, instanceId}
thread:history threadId {ok:true, thread, messages}
thread:archive threadId {ok:true, threadId}
thread:rename threadId、name {ok:true, threadId, name}
thread:delete threadId {ok:true, threadId}

服务端到客户端事件

agent:event 信封

所有事件通过单一 agent:event 信封下发：

graph TB subgraph "agent:event 信封" A[seq: 自增序号] B[epoch: 服务端标识] C[sessionId] D[instanceId] E[cwd] F[ts: 时间戳] G[type: 事件类型] H[payload: 载荷] end

事件类型

type 用途
init 连接建立、线程选中初始化
status 会话状态快照（busy/idle）
status_line git + context 状态行
text_delta 助手文本增量
reasoning 推理增量/摘要
tool_use 工具调用开始
tool_result 工具调用结果
tool_output_delta 工具输出增量
approval_request 审批请求
user_input_request 用户输入请求
approval_revoked 审批撤销
result turn 终态
error 错误
system 系统消息
instances 实例列表
session_list 会话列表
thread_event 原生线程事件
raw_item 未识别 item 的兜底信封
