项目定位

codex-chat-mobile 是 Codex CLI 的本地 rich client。它不把工作代理到托管后端；浏览器连接本机 Node 服务，Node 服务再连接本机 codex app-server 进程。

核心理念
无托管后端：浏览器直连本机，不经过任何云服务
本地控制面：在手机上获得与终端等效的体验
安全默认：空 AUTH_TOKEN 只允许 loopback，审批不自动决议

解决什么问题

Codex CLI 是一个强大的 AI 编程助手，但它只能在终端中使用。当你离开电脑时：

  • 无法批准正在等待的命令执行请求
  • 无法查看长时间运行的任务进度
  • 无法在手机上继续对话

codex-chat-mobile 解决这些问题：让你在手机上获得与终端等效的体验，同时保持本地运行的安全性。

核心特性

流式对话

文本增量、推理过程、命令输出实时呈现。支持 reasoning 分区渲染，不混入正文。

审批卡片

在手机上批准或拒绝命令/文件操作。审批到达时可触发 Web Push 通知。

多实例标签

隔离多个活跃对话，互不串流。支持多工作区路由。

原生控制

线程管理（list/resume/archive/rename/delete）、模型切换、文件浏览。

技术栈

后端
Node.js ≥ 20 + Express 5 + Socket.IO
前端
HTML/CSS shell + 外部 ESM（public/index.html + public/js/app.js）
协议
JSON-RPC 2.0 over stdio（连接 codex app-server）
认证
AUTH_TOKEN（timing-safe 比较）+ 设备信任
推送
Web Push（VAPID）
测试
node:test + Playwright E2E

职责边界：

  • server.js：HTTP、Socket.IO、鉴权、路由、实例生命周期
  • agent-appserver.js：JSON-RPC 桥、事件映射、审批代理
  • public/index.html：移动端 PWA 的 HTML/CSS shell
  • public/js/app.js：UI 渲染、交互和浏览器应用编排
  • codex app-server：AI 对话、工具执行、文件操作
