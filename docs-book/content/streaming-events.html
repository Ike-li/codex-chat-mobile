事件流概述

流式事件处理是 codex-chat-mobile 的核心能力：从 app-server 通知到前端渲染的完整数据流。

graph LR A[codex app-server] -->|JSON-RPC 通知| B[agent-appserver.js] B -->|agent:event 信封| C[server.js] C -->|Socket.IO| D[浏览器]

事件映射

agent-appserver.js 将 app-server 通知映射为 agent:event 信封：

app-server 通知 agent:event type 用途
item/started — item 开始（内部状态）
item/agentMessage/delta text_delta 文本增量
item/reasoning/textDelta reasoning 推理增量
item/commandExecution/outputDelta tool_output_delta 命令输出增量
item/completed 多种 item 完成（按 type 分类）
turn/completed result turn 完成
thread/archived thread_event 线程归档

信封格式

所有事件通过单一 agent:event 信封下发：

graph TB subgraph "agent:event 信封" A[seq: 自增序号] B[epoch: 服务端标识] C[sessionId] D[instanceId] E[cwd] F[ts: 时间戳] G[type: 事件类型] H[payload: 载荷] end

信封字段

字段 类型 说明
seq number 自增序号，用于 catch-up
epoch string 服务端 epoch 标识
sessionId string|null 当前会话 ID
instanceId string|null 当前实例 ID
cwd string 工作目录
ts number Date.now() 时间戳
type string 事件类型
payload object 类型相关载荷

事件类型详解

文本事件

type payload 用途
text_delta {text, channel} 助手文本增量
reasoning {text, channel, kind} 推理增量/摘要

工具事件

type payload 用途
tool_use {name, input} 工具调用开始
tool_result {name, output, exitCode} 工具调用结果
tool_output_delta {text} 工具输出增量
mcp_use {server, tool, arguments} MCP 工具调用
mcp_result {server, tool, result} MCP 工具结果

文件事件

type payload 用途
file_change {path, type} 文件变更总结
diff {path, diff} diff 内容
plan {plan} 计划面板

审批事件

type payload 用途
approval_request {approvalId, kind, command, reason} 审批请求
user_input_request {questions} 用户输入请求
approval_revoked {approvalId} 审批撤销

状态事件

type payload 用途
status {busy, sessionState} 会话状态快照
status_line {cwd, sandbox, approvalPolicy, ...} git + context 状态行
result {ok, status, message} turn 终态
error {message, recoverable} 错误
system {message, isError} 系统消息

前端渲染

文本渲染

  • text_delta：追加到助手文本区域
  • reasoning：渲染到折叠的 reasoning 区块

工具渲染

  • tool_use：显示命令卡片（开始状态）
  • tool_result：更新命令卡片（结果状态）
  • tool_output_delta：追加输出到命令卡片

文件渲染

  • file_change：显示文件变更总结
  • diff：显示 diff 面板
  • plan：显示计划面板

审批渲染

  • approval_request：显示审批卡片
  • user_input_request：显示用户输入表单
  • approval_revoked：移除审批卡片

未知类型降级

当前端遇到不认识的 item type 时：

graph LR A[app-server 通知] --> B{识别 type?} B -->|是| C[正常渲染] B -->|否| D[raw_item 信封]

raw_item 信封显示原始 JSON，确保未知类型不丢失。
