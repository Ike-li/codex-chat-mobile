远程访问方案

HTTPS/PWA/Push 的硬限制与解决方案。

阅读约 12 分钟 第 21 / 27 篇 源自 docs/REMOTE_ACCESS.md

远程访问概述

codex-chat-mobile 设计为本地控制面，但支持从手机远程访问。远程访问有硬限制：必须 HTTPS 才能使用 PWA 和 Web Push。

硬限制
PWA：必须 HTTPS 或 localhost
Web Push：必须 HTTPS
AUTH_TOKEN：非 loopback 必须设置

访问方式

方式一：局域网 HTTP

最简单，但功能受限：

  • 配置：HOST=0.0.0.0 + AUTH_TOKEN=强token
  • 访问：http://<开发机IP>:3001
  • 限制：装不了 PWA、收不到推送

方式二：Tailscale Serve

推荐方案，零配置 HTTPS：

  1. 安装 Tailscale：开发机和手机都安装
  2. 启用 Serve：tailscale serve --bg 3001
  3. 访问：https://<设备名>.ts.net
Tailscale 优势
零配置 HTTPS：自动证书
内网穿透：不在同一局域网也能访问
安全：WireGuard 加密

方式三：反向代理

自定义域名 + 证书：

  1. 配置 Nginx/Caddy：反向代理到 3001
  2. 申请证书：Let's Encrypt
  3. 访问：https://your-domain.com

配置详解

HOST 绑定

值 行为
127.0.0.1 仅本机访问
0.0.0.0 所有网络接口
:: IPv6 所有接口

AUTH_TOKEN

  • 空：仅允许 loopback
  • 非空：允许非 loopback，timing-safe 比较
安全要求
非 loopback 访问 必须 设置 AUTH_TOKEN，否则拒绝连接。

PWA 安装

前提条件

  • 安全上下文：HTTPS 或 localhost
  • manifest：manifest.webmanifest
  • Service Worker：js/sw.js

安装步骤

平台 步骤
iOS Safari 分享 → 添加到主屏幕
Android Chrome 菜单 → 安装应用

standalone 模式

安装后以 standalone 全屏运行：

  • 无地址栏：全屏体验
  • 竖屏/横屏：自动适应
  • 软键盘：composer 控件保持可见

Web Push

前提条件

  • HTTPS：必须
  • VAPID 密钥：三个都配置

配置

变量 说明
VAPID_SUBJECT mailto:your@email.com
VAPID_PUBLIC_KEY 公钥
VAPID_PRIVATE_KEY 私钥

生成密钥

命令
npx web-push generate-vapid-keys

推送场景

  • 审批到达：approval_request
  • 用户输入请求：user_input_request
  • 任务完成：result
  • 任务出错：error

设备信任

首次连接

  1. 输入 AUTH_TOKEN：登录页
  2. 设备审批：新设备可能需已信任设备批准
  3. 保存信任：通过后保存在该浏览器

设备审批流

sequenceDiagram participant B as 新设备 participant S as server.js participant T as 已信任设备 B->>S: 连接 S->>S: 检查设备信任 S->>T: pending_devices 信封 T->>S: user:approveDevice S->>B: 允许连接

排错清单

装不了 PWA

  • 检查是否 HTTPS（或 localhost）
  • 检查 manifest 是否正确
  • 检查 Service Worker 是否注册

收不到推送

  • 检查是否 HTTPS
  • 检查 VAPID 是否配置
  • 检查浏览器通知权限

手机无法连接

  • 检查 HOST=0.0.0.0
  • 检查 AUTH_TOKEN 非空
  • 检查同一局域网
  • 检查防火墙
