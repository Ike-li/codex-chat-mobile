能力总览

一张表看清所有核心能力。

阅读约 8 分钟 第 11 / 27 篇 源自 docs/API.md

核心能力矩阵

能力 模块 状态 说明
流式对话 agent-appserver.js 稳定 文本增量、reasoning、命令输出
审批系统 approval-broker.js 稳定 命令/文件/权限审批
多实例 server.js 稳定 标签隔离、工作区路由
文件上传 uploads.js 稳定 校验、限量、owner-only
Web Push push.js 稳定 VAPID 推送通知
断线恢复 server.js 稳定 catch-up 增量补发
原生控制 agent-appserver.js 稳定 线程管理、模型切换
PWA public/index.html 稳定 可安装、standalone
Admin 操作 server.js 稳定 配置写入、文件操作（门控）
Labs 实验 agent-appserver.js 实验 网页终端、历史搜索（feature flag）

能力详情

流式对话

从 app-server 到前端的完整事件流：

  • 文本增量：item/agentMessage/delta
  • 推理过程：item/reasoning/textDelta（channel/kind 分区渲染）
  • 命令输出：item/commandExecution/outputDelta
  • 工具调用：item/tool_use、item/tool_result

审批系统

四种审批类型：

  • 命令执行：item/commandExecution/requestApproval
  • 文件变更：item/fileChange/requestApproval
  • 权限请求：item/permissions/requestApproval
  • 用户输入：item/tool/requestUserInput

多实例

每个实例独立：

  • app-server 子进程：独立进程
  • 会话状态：独立 thread
  • 输入队列：独立队列
  • 审批状态：独立 pending

文件上传

安全上传流程：

  1. 校验：类型、大小、数量
  2. 落盘：owner-only 权限
  3. 注入：绝对路径注入 turn/start

Web Push

推送场景：

  • 审批到达：approval_request
  • 用户输入请求：user_input_request
  • 任务完成：result
  • 任务出错：error

断线恢复

恢复机制：

  1. seq 追踪：每个信封带自增 seq
  2. 环形缓冲：保留最近 N 个信封
  3. 增量补发：从 lastSeq 开始补发

原生控制

线程管理：

  • thread:list — 列出线程
  • thread:select — 选择线程
  • thread:history — 读取历史
  • thread:archive — 归档线程
  • thread:rename — 重命名线程
  • thread:delete — 删除线程
  • thread:compact — 压缩线程
  • thread:rollback — 回退线程

Admin 操作

门控操作：

  • 解锁：admin:unlock（短语 ENABLE ADMIN）
  • 配置写入：admin:configWrite、admin:configBatchWrite
  • 文件操作：admin:fsWriteFile、admin:fsRemove、admin:fsCopy
  • 插件管理：admin:pluginInstall、admin:pluginUninstall
  • MCP 调用：admin:mcpToolCall

Labs 实验

需 CODEX_P3_EXPERIMENTAL=1：

  • 网页终端：p3:terminalSpawn、p3:terminalWrite
  • 历史搜索：p3:threadTurns、p3:threadSearch
  • 实时语音：仅跟踪通知
