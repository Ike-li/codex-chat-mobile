Codex 协议集成

JSON-RPC 2.0 over stdio 的实现细节。

阅读约 12 分钟 第 18 / 27 篇 源自 docs/PROTOCOL.md · agent-appserver.js

JSON-RPC 2.0 over stdio

codex-chat-mobile 通过 JSON-RPC 2.0 over stdio 连接 codex app-server 子进程。

传输方式
stdio NDJSON：标准输入输出，每行一个 JSON 对象
长驻子进程：每个实例一个独立进程
零网络配置：不需要开放端口

JSON-RPC 帧格式

请求

graph LR A[Client Request] --> B[JSON-RPC 2.0] B --> C[stdin → app-server]

格式：

请求格式
{"id": 1, "method": "turn/start", "params": {"input": [...]}}

响应

graph LR A[app-server] --> B[JSON-RPC 2.0] B --> C[stdout → Client]

格式：

响应格式
{"id": 1, "result": {"threadId": "..."}}

通知

graph LR A[app-server] --> B[JSON-RPC 2.0] B --> C[stdout → Client]

格式：

通知格式
{"method": "item/agentMessage/delta", "params": {"text": "..."}}

请求 ID 管理

pending Map

graph TB A[发送请求] --> B[分配 id] B --> C[pending.set(id, {resolve, reject})] D[收到响应] --> E[pending.get(id)] E --> F[resolve/reject] F --> G[pending.delete(id)]

超时处理

  • 无超时：请求不设超时（等待用户审批）
  • 进程退出：子进程退出时 reject 所有 pending
  • 错误响应：收到 error 时 reject

通知处理

handleNotification

graph TD A[收到通知] --> B{method?} B -->|item/started| C[处理 item 开始] B -->|item/*/delta| D[处理增量] B -->|item/completed| E[处理 item 完成] B -->|turn/completed| F[处理 turn 完成] B -->|thread/*| G[处理线程事件] B -->|其他| H[default 分支]

default 分支

未处理的通知走 default 分支：

  • 不报错
  • 不阻塞
  • RPC 日志记录

Server Request 处理

handleServerRequest

graph TD A[收到 S→C 请求] --> B{method?} B -->|审批类| C[ApprovalBroker.handleRequest] B -->|account/chatgptAuthTokens/refresh| D[显式拒绝] B -->|其他| E[Unsupported server request]

审批类请求

  • item/commandExecution/requestApproval
  • item/fileChange/requestApproval
  • item/permissions/requestApproval
  • item/tool/requestUserInput

RPC 日志

日志格式

记录到 .codex-chat-rpc.jsonl：

日志格式
{"ts": 1720000000000, "dir": "inbound", "type": "request", "method": "turn/start", "id": 1}

敏感字段过滤

日志中过滤敏感字段：

  • token、secret、password
  • authorization、api_key
  • private_key、refreshToken
  • dataBase64

背压重试

-32001 处理

graph LR A[发送请求] --> B[收到 -32001] B --> C[指数退避] C --> D[重试] D --> E{成功?} E -->|是| F[继续] E -->|否| G[达到上限?] G -->|否| C G -->|是| H[报错]

退避参数

参数 默认值 说明
backpressureRetries 5 最大重试次数
backpressureBaseMs 250 基础退避时间
maxBackpressureDelayMs 5000 最大退避时间

错误处理

JSON-RPC 错误

错误码 含义
-32600 Invalid Request
-32601 Method not found
-32602 Invalid params
-32001 Server overloaded

错误恢复

  • 请求错误：reject pending
  • 进程崩溃：reject all pending，重启
  • 背压：指数退避重试
