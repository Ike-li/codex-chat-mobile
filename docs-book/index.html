它是什么

codex-chat-mobile 是 Codex CLI 的本地 rich client。它不把工作代理到托管后端；浏览器连接本机 Node 服务，Node 服务再连接本机 codex app-server 进程。

graph LR A[手机浏览器 / PWA] -->|Socket.IO| B[server.js] B -->|JSON-RPC| C[agent-appserver.js] C -->|stdio| D[codex app-server]

核心特性

  • 流式对话：文本增量、推理过程、命令输出实时呈现
  • 审批卡片：在手机上批准或拒绝命令/文件操作
  • 多实例标签：隔离多个活跃对话，互不串流
  • 原生控制：线程管理、模型切换、文件浏览
  • Web Push：审批到达时推送通知
  • PWA 安装：standalone 全屏运行
